# Titan

Минималистичный нативный Android-клиент для частного инвестора — без рекламы
и лишних функций. Только то, что нужно: портфель, котировки с графиком, сделки и
история операций.

Работает поверх публичного **T-Invest API** (REST/JSON-шлюз) в двух режимах:

- **Песочница** — виртуальные деньги, реальные котировки, торговля доступна.
- **Реальный счёт** — данные настоящего счёта через **read-only токен**.
  Торговля в этом режиме **полностью отключена** (только просмотр).

> Неофициальное приложение, не связано с каким-либо брокером. Название «Titan»
> отсылает к титану (Ti) и инвестициям.

## Возможности

- **Портфель** — стоимость, изменение в деньгах и процентах с переключателем
  **День / За всё время**. Позиции сгруппированы на **Замороженные** (иностранные,
  фонды FinEx, неторгуемое в валюте) и **Ликвидные** (российские) с подгруппами
  Акции / Облигации / Фонды / Другие; у каждой группы — подытог в рублях.
  При нескольких счетах — **консолидированный** вид с проваливанием в каждый.
- **Обзор рынка** — сворачиваемая сводка ключевых активов (доллар, индекс
  МосБиржи, золото, нефть Brent, биткоин) с котировками прямо на экране портфеля.
- **Рынок** — двухуровневая навигация: разделы **Акции / Облигации / Фонды** и
  подразделы (Акции → Голубые фишки/Все; Облигации → ОФЗ/Корпоративные/Регионы),
  плюс поиск по тикеру/названию/ISIN. В строках — иконки и котировки.
- **Инструмент** — цена и дневное изменение, лучшие bid/ask, график **линией или
  свечами** (переключатель) с сеткой и подписями уровней; таймфреймы 1Д / 1Н / 1М / 6М / 1Г.
- **Торговля** — рыночные и лимитные заявки (только песочница); неторгуемые
  инструменты отсекаются заранее.
- **Операции** — история сделок, комиссий, дивидендов и купонов за 90 дней.
- **Два режима, два токена** — песочный и реальный read-only хранятся раздельно;
  в реальном режиме торговля полностью отключена. Режим переключается в настройках.
- **Иконки инструментов** — логотипы брендов из CDN Т-Инвестиций (Coil), с
  монограммой-заглушкой при отсутствии.
- **Безопасность** — токены хранятся в `EncryptedSharedPreferences`, исключены из
  бэкапов, не попадают в логи.

## Технологический стек

| Слой        | Технология                                              |
|-------------|---------------------------------------------------------|
| Язык        | Kotlin 2.0                                              |
| UI          | Jetpack Compose + Material 3 (тёмная тема)              |
| Архитектура | MVVM (ViewModel + StateFlow), репозиторий, ручной DI    |
| Сеть        | Retrofit + OkHttp + kotlinx.serialization              |
| Навигация   | Navigation Compose                                      |
| Изображения | Coil (логотипы инструментов)                            |
| Графики     | Canvas (свечи/линия, без сторонних библиотек)          |
| Хранилище   | androidx.security EncryptedSharedPreferences           |
| CI          | GitHub Actions (сборка debug/release APK)              |

## Сборка

Требуется **Android Studio** (Ladybug или новее) либо Android SDK с `compileSdk 35`.

```bash
./gradlew assembleDebug      # debug-APK → app/build/outputs/apk/debug/
./gradlew installDebug       # установить на подключённое устройство/эмулятор
```

Открой проект в Android Studio и нажми **Run** — это самый простой путь.

На каждый push в PR **GitHub Actions** собирает debug- и release-APK и
публикует их как артефакты (`tinvest-lite-debug` / `tinvest-lite-release`) —
их можно скачать со страницы прогона во вкладке **Actions**.

## Подпись APK

Все сборки (включая debug-APK из CI) подписываются **одним фиксированным ключом**
`keystore/tinvest-lite.jks` (alias/пароль: `tinvestlite`). Благодаря этому новую
версию можно установить **поверх** предыдущей без удаления — Android требует
совпадения подписи для обновления.

> Ключ намеренно лежит в репозитории и подходит только для сайдлоада/песочницы.
> Для публикации в Google Play понадобится отдельный релизный ключ в GitHub Secrets.

**Релизная подпись** (распространяемый вариант) использует отдельный ключ из
GitHub Secrets — приватный ключ не хранится в репозитории. Настройка описана в
[`docs/SIGNING.md`](docs/SIGNING.md).

## Как получить API-токен

1. Зайди в веб-кабинет Т-Инвестиций (`t-invest.tinkoff.ru`).
2. **Настройки → Токены для T-Invest API → создать токен**.
3. Для **песочницы** подойдёт токен с полным доступом — введи его на экране входа.
4. Для **реального счёта** создай **отдельный токен «только чтение»** и добавь его в
   приложении: вкладка «Настройки» → раздел «Реальный счёт». Этот токен физически не
   может торговать, а приложение в реальном режиме и не отправляет заявки.

Любой токен можно отозвать в том же разделе кабинета в любой момент.

## Заметки по реализации

- API-методы вызываются через публичный REST-шлюз
  `https://invest-public-api.tinkoff.ru/rest/<package>.<Service>/<Method>`.
- Песочница использует `SandboxService`; реальный режим (только чтение) —
  `UsersService.GetAccounts`, `OperationsService.GetPortfolio/GetOperations`.
- Шлюз сериализует поля `int64` (`units`, `quantity`, …) как строки в кавычках,
  поэтому JSON-парсер настроен в режиме `isLenient`.
- Счёт песочницы создаётся автоматически при первом входе; пополнить его виртуальными
  деньгами можно на вкладке «Настройки».
- Котировки в списках и дневное изменение собираются батч-запросами
  `GetLastPrices` + `GetClosePrices`.
- «Голубые фишки» — курируемый список тикеров индекса МосБиржи (iMOEX), так как
  отдельного эндпоинта у API нет.
- Подытог «Замороженные» в рублях считается как `стоимость счёта − ликвидные − кэш`,
  чтобы не конвертировать валютные позиции по курсу.
